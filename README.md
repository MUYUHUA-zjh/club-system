# 社团云 · 大学社团管理系统（MVP）

基于 spec 文档（`社团系统spec/大学社团管理系统-Spec文档.md`）第七章 P0 范围实现的最小可行产品。

## 技术栈

| 端 | 技术 |
|----|------|
| 前端 | Vue 3 + TypeScript + Vite + Tailwind CSS v4 + Pinia + Vue Router |
| 后端 | Node.js 22 + Express + node:sqlite（内置 SQLite，零原生依赖） |
| 鉴权 | JWT + bcryptjs |
| UI 风格 | 参考 Claude 官网：米白底 `#F7F5F0`、珊瑚橙 `#D97757`、衬线标题、细边框大圆角 |

## 快速启动

```bash
# 1. 启动后端（端口 3001，首次启动自动建表并写入演示数据）
cd server
npm install
npm start          # 等价于 node --experimental-sqlite src/index.js

# 2. 启动前端（端口 5173，已配置 /api 代理）
cd web
npm install
npm run dev
```

浏览器访问 http://localhost:5173

## MVP 功能清单（对齐 spec P0）

- 用户体系：学号注册 / 登录 / 退出，管理员 / 社长 / 学生三角色，菜单级权限隔离
- 社团管理：社团 CRUD、七大分类、成立申请与管理员审核（驳回需填写原因，通过后发起人自动成为社长）
- 成员管理：入社申请 / 审核 / 成员列表搜索 / 主动退社 / 社长移除
- 活动管理：发布 / 列表 / 详情 / 报名 / 取消 / 名额限制（事务防超报）/ 动态二维码签到（60 秒刷新，±1 分钟窗口校验）/ 报名名单 CSV 导出
- 通知公告：全校公告（管理员）+ 社团通知（社团管理者）、已读 / 未读、未读数角标
- 数据统计：管理员大盘（社团数 / 用户数 / 本月活动 / 待办 / 类型分布 / TOP10）、社团看板、个人数据
- 个人中心：资料修改、我的社团、我的活动

## V1.1 新增功能

- 同学录（我的同学）：全站注册用户浏览，按年级 / 学院 / 专业筛选 + 姓名学号搜索，手机号脱敏
- 好友系统：学号查找或同学录一键添加，申请 / 通过 / 忽略 / 双向互加自动通过，未读申请角标
- 站内聊天：一对一文字消息（仿微信气泡界面），会话列表、未读计数、3 秒轮询刷新、阅读自动清零
- 管理员用户管理：全量用户档案（联系方式未脱敏）、详情查看、禁用 / 启用账号、重置密码
- 修复：通知未读红点阅读后不消失的问题（全局响应式未读状态，阅读即减、路由切换自动刷新）

## 目录结构

```
club-system/
├── server/               # 后端
│   ├── src/
│   │   ├── index.js      # Express 入口、静态文件、上传
│   │   ├── db.js         # node:sqlite 建表 + 种子数据
│   │   ├── auth.js       # JWT / 权限中间件 / 签到码生成
│   │   └── routes.js     # 全部业务 API
│   ├── data/club.db      # SQLite 数据库（首次启动生成）
│   └── test-api.mjs      # 四条核心链路端到端测试
└── web/                  # 前端
    └── src/
        ├── layout/       # 侧边栏布局
        ├── views/        # 11 个页面
        ├── api.ts        # Axios 封装 + 类型
        ├── stores.ts     # Pinia 认证状态
        └── style.css     # Claude 风格设计系统
```
